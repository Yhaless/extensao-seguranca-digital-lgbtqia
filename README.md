# Rede Segura: Educação em Segurança Digital e Privacidade para Pessoas Trans e LGBTQIA+

Projeto de extensão desenvolvido individualmente para a disciplina de Gerência de Projetos — Redes de Computadores, UFC Campus Quixadá.

## Sobre o projeto

Este projeto tem como objetivo desenvolver materiais educativos sobre segurança digital e violência online voltados especificamente aos riscos enfrentados por pessoas trans e LGBTQIA+ (doxxing, discurso de ódio, imagens íntimas não consentidas/deepfakes, entre outros), com dois públicos complementares:

1. **A própria comunidade LGBTQIA+** — ferramentas práticas de proteção.
2. **O público em geral** — conscientização sobre como esses ataques acontecem e o dano real que causam.

## Integrante

- Yhales — Redes de Computadores, UFC Quixadá

## Estrutura do repositório

- `docs/` — proposta do projeto, cronograma e documentação de gestão
- `pesquisa/` — levantamento de riscos digitais, dados e fontes
- `conversas-comunidade/` — registros das conversas com pessoas trans/LGBTQIA+ consultadas durante o desenvolvimento
- `roteiros/` — roteiros dos materiais educativos em produção
- `materiais-finais/` — versões finais dos materiais (vídeos, cartilhas, etc.)
